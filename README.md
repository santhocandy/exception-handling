# ExceptionHandling Project

This project demonstrates various examples of exception handling in Java. It covers different types of exceptions and provides examples to correctly handle them for robust application development.

## Included Examples
- CompileTimeException
- RuntimeException

The project primarily focuses on compile-time and runtime exceptions, showcasing how to manage them effectively to build robust applications.

Ensure you have Java installed to run these examples. Use the command `javac` to compile the files and `java` to execute them.
